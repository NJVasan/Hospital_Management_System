Project Title:
Hospital Patient Management System

Overview:

The Hospital Patient Management System is a web application developed using Java Servlets, JSP, JDBC, and MySQL. It allows users to manage patient records efficiently through a simple and user-friendly interface.

Features:

- Dashboard
- Add Patient
- View Patients
- Update Patient
- Delete Patient
- Search Patient

Technologies Used:

- Java
- JSP
- Jakarta Servlets
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat

Database:

- Database: `hospitaldb`
- Table: `patient`
